# Submission

Where to start reading. The brief evaluates how the AI was directed, not only what it built.

- **What was built and why:** [`feature-design/`](feature-design/). The local demo is done and frozen in [`feature-design/local-demo/`](feature-design/local-demo/): its [product spec](feature-design/local-demo/product-spec.md), [roadmap](feature-design/local-demo/roadmap.md), milestone specs M1 to M5 and findings. The MVP is the current phase, with its spec at [`feature-design/product-spec.md`](feature-design/product-spec.md) and its roadmap in [`feature-design/mvp/`](feature-design/mvp/).
- **How the work was directed:** [`workflow.md`](workflow.md) describes the agents and the gates, and [`process-logs/process-logs.md`](process-logs/process-logs.md) explains the four logs.
- **The logs, phase by phase:** [`process-logs/phases.md`](process-logs/phases.md) lists every phase's folder and the ID range each one covers.

Agents read the design documents here, but are barred from `process-logs/` to save tokens. Only the main session writes the logs.
